# יאללה מדברים 🫒 ערבית מדוברת לדוברי עברית

אפליקציית ווב לנייד ללימוד ערבית מדוברת של ערביי ארץ ישראל (בהגייה של המשולש). הכל בתעתיק עברי, עם הקראה בקול, תרגול דיבור, מבחן רמה, תוכנית אישית וחזרה מרווחת.

## איך משתמשים בטלפון
1. פותחים את הקישור של האתר ב-Chrome (אנדרואיד) או ב-Safari (אייפון).
2. **אנדרואיד:** תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה".
   **אייפון:** כפתור השיתוף ← "הוסף למסך הבית".
3. מעכשיו יש אייקון ע על המסך, והאפליקציה נפתחת כמו אפליקציה רגילה.

## נתונים
ההתקדמות (רמה, מילים, ימי תרגול) נשמרת רק בטלפון של המשתמש, ולכן לכל משתמש יש נתונים נפרדים. מחיקת נתוני הדפדפן מוחקת גם את ההתקדמות.

## עדכונים
מעדכנים את `index.html` בריפו, ו-GitHub Pages מפרסם את השינוי תוך דקה או שתיים. בפעם הבאה שפותחים את האפליקציה בטלפון, הגרסה החדשה נטענת לבד. לא צריך להתקין שוב, וההתקדמות נשמרת.

## קבצים
- `index.html`: כל האפליקציה (קובץ אחד)
- `SPEC.md`: קובץ האפיון והמחקר
- `manifest.webmanifest`, `icon-*.png`: אייקון והתקנה למסך הבית
